# Mass-Shift Guidance Control System

질량 이동(Mass-Shift) 방식과 시커(Seeker) 추적 기능을 결합한 유도·제어 프로토타입 프로젝트입니다.

Raspberry Pi 기반으로 센서 데이터를 수집하고, 표적 위치에 따라 서보모터 및 스텝모터를 제어하여 시커 방향 조정과 질량 이동 제어를 구현하는 것을 목표로 진행했습니다.

---

## 1. 프로젝트 개요

본 프로젝트는 이동 질량을 이용한 자세 및 방향 제어 원리를 직접 구현하고, 초음파 센서 기반 시커 추적 시스템과 연동하여 유도·제어 시스템의 기본 구조를 검증하기 위해 진행했습니다.

단순 모터 구동에 그치지 않고 센서 입력, 표적 추적, 모터 제어, 중심점 보정, 하드웨어 설계 및 통합 테스트까지 전체 시스템을 직접 구현했습니다.

---

## 2. 주요 기능

- 초음파 센서를 이용한 표적 위치 탐지
- Pan/Tilt 구조의 시커 방향 제어
- 서보모터 기반 시커 추적
- 스텝모터 기반 질량 이동 제어
- IMU를 활용한 자세 데이터 측정
- 센서 및 모터 중심값 캘리브레이션
- Raspberry Pi 기반 실시간 제어
- Linux 환경에서의 빌드 및 디버깅
- Git/GitHub를 활용한 소스코드 형상관리

## 3. 시스템 구성

### Controller
- Raspberry Pi 4B

### Sensors
- SRF-05 Ultrasonic Sensor ×3
- MPU-6050 IMU

### Actuators
- Servo Motor
- Stepper Motor
- Linear Actuator

### Motor / Servo Driver
- PCA9685
- A4988

### Development Environment
- C++
- Linux
- VS Code
- SSH
- Git / GitHub

---

## 4. 시스템 동작 구조

1. 초음파 센서를 통해 표적 위치를 측정
2. 센서 간 거리 차이를 이용하여 표적 방향 판단
3. Pan/Tilt 서보모터를 제어하여 시커 방향 보정
4. 표적 위치 및 자세 정보를 기반으로 질량 이동 방향 결정
5. 스텝모터 및 액추에이터를 제어하여 질량 이동 수행
6. 반복 측정을 통해 목표 방향으로 지속적인 제어 수행

---

## 5. 주요 구현 내용

### 초음파 기반 표적 추적
다수의 초음파 센서에서 측정된 거리 값을 비교하여 표적의 좌우 및 상하 방향을 판단하고, 이에 따라 시커의 Pan/Tilt 각도를 조정하도록 구현했습니다.

### 서보모터 제어
PCA9685를 이용하여 Pan/Tilt 서보모터를 제어하고, 센서가 동체 정면을 바라보도록 PWM 중심값을 직접 캘리브레이션했습니다.

### 질량 이동 제어
A4988 드라이버와 스텝모터를 이용하여 내부 질량 이동 장치를 구동하고, 목표 위치에 따라 질량의 이동 방향과 이동량을 제어하도록 구성했습니다.

### IMU 데이터 활용
MPU-6050 센서 데이터를 통해 자세 상태를 확인하고 초기 바이어스 값을 보정하여 제어에 활용할 수 있도록 구현했습니다.

## 6. 문제 해결 과정

프로젝트 진행 중 다음과 같은 문제를 확인하고 개선했습니다.

- 초음파 센서 간 간섭 및 측정 실패
- 센서 전압 레벨 문제
- 레벨시프터 및 배선 오류
- Pan/Tilt 중심축 오차
- 서보모터 진동 및 과도한 제어
- 스텝모터 이동 방향 및 중심값 오차
- 센서 측정 주기 조정을 통한 안정성 개선

각 문제에 대해 센서 단독 테스트, 배선 검증, PWM 및 제어값 조정, 캘리브레이션 코드 작성 등을 통해 원인을 분석하고 개선했습니다.
